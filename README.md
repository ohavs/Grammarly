# WriteRight

Real-time writing assistant: grammar, spelling, style, and clarity suggestions.

## Structure

```
backend/   - API server (Node.js + Fastify + LanguageTool)
web/       - Web client (React + Vite + TypeScript)
desktop/   - Electron wrapper (later)
shared/    - Shared types between frontend and backend
```

## Development

```bash
npm install
npm run dev
```
